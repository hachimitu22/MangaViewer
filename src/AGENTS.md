# AGENTS.md (src)

このファイルのスコープは `src/` 配下です。ルート `AGENTS.md` より本ファイルを優先します。

## 目的
- レイヤ境界を維持し、機能追加・修正時に責務の混在を防ぐ。
- 最小差分で変更し、既存の公開契約を壊さない。

## レイヤ運用
- `domain/`
  - エンティティ・値オブジェクトなどのドメインロジックを置く。
  - I/O やフレームワーク依存を持ち込まない。
- `application/`
  - ユースケース（command/query/app）を置く。
  - ドメインの調停に専念し、Web/UI 依存を持たせない。
- `infrastructure/`
  - ORM、ストレージ、認証アダプタなど外部依存を扱う。
  - 失敗時は既存方針どおり fail-close を維持する。
- `controller/`
  - Router / Middleware / Controller の HTTP 境界を扱う。
  - バリデーション・認可の順序を既存実装に合わせる。
- `views/`
  - EJS テンプレートのみを扱い、ビジネスロジックを持たせない。

## 実装時の注意
- `applicationService` 旧系テストとの整合を壊さないよう、既存命名と import を維持する。
- 命名変更が必要な場合は `doc/` と `__tests__/` の basename まで同時に追従する。
- 依頼がない限り、以下は変更しない:
  - ルーティングパス
  - API レスポンス契約
  - セッション/認証の既定動作

## 変更前チェック
- 変更対象が本当にこのレイヤかを確認する。
- レイヤ越境（例: `views` から `infrastructure` 参照）が発生していないか確認する。
