# AGENTS.md (__tests__)

このファイルのスコープは `__tests__/` 配下です。ルート `AGENTS.md` より本ファイルを優先します。

## 目的
- テスト粒度（small / medium / large）を維持し、責務に応じて適切な階層へ配置する。

## 配置ルール
- `small/`
  - 単体テスト。外部依存はモックまたはインメモリで扱う。
  - 1ファイルの責務を絞り、失敗原因を特定しやすくする。
- `medium/`
  - レイヤ間結合を含むテスト。コントローラやアプリケーション連携を検証する。
- `large/e2e/`
  - 画面遷移や認証を含む E2E。ユーザーシナリオ単位で検証する。
- `helpers/`
  - 共通ユーティリティのみを配置し、仕様ロジックを持ち込まない。

## 命名ルール
- basename は可能な限り `src/` と `doc/` に揃える。
- テスト名は「何を守るテストか」が読める表現にする。

## 追加・修正時の注意
- 不具合修正時は、再発防止となるテストを先に追加または同時追加する。
- ログや時刻依存の揺らぎがある場合は、テストで固定化する。
- 認証関連の変更では `small` と `large/e2e/auth` の両方で回帰観点を持つ。
