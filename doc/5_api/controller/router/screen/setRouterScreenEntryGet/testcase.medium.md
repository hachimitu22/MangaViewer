### GET /screen/entry に描画ハンドラーを登録する
- **前提**
  - `router.get` をモック化する。
- **操作**
  - `setRouterScreenEntryGet` を実行する。
- **結果**
  - `router.get` が1回呼ばれる。
  - 第1引数が `/screen/entry` である。
  - 第2引数以降にハンドラーが設定される。

---

### 登録済みハンドラーを実行すると登録画面を描画する
- **操作**
  - 登録済みハンドラーを実行する。
- **結果**
  - `screen/entry` がカテゴリ候補とタグ候補を含む表示データで描画される。
