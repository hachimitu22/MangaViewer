## 異常系

### dir未指定ならusageを出力して終了コード3で終了する
- **前提**
  - CLI引数に `<dir>` が指定されていない。
- **操作**
  - `npm run import` を実行する。
- **結果**
  - usage がログに出力される。
  - 終了コードが3となる。

### dirが存在しない場合は即失敗で終了する
- **前提**
  - 指定した `<dir>` が存在しない、または読み取り不可である。
- **操作**
  - `npm run import -- <dir>` を実行する。
- **結果**
  - `error` ログに失敗理由が出力される。
  - zip処理ループは開始されない。
  - 終了コードは3となる。

### dirがファイルの場合は終了コード4で終了する
- **前提**
  - 指定した `<dir>` が存在するファイルであり、ディレクトリではない。
- **操作**
  - `npm run import -- <dir>` を実行する。
- **結果**
  - `error` ログにディレクトリではない理由が出力される。
  - zip処理ループは開始されない。
  - 終了コードは4となる。

### 解凍エラーのzipは失敗として次zipへ継続する
- **前提**
  - 直下に「壊れたzip」と「正常zip」が存在する。
- **操作**
  - import を実行する。
- **結果**
  - 壊れたzipは失敗ログが記録される。
  - 正常zipの処理は継続される。
  - 全体終了コードは非0となる。

### 暗号化zipは非対応として失敗し理由をログに出力する
- **前提**
  - 直下に暗号化zipが存在する。
- **操作**
  - import を実行する。
- **結果**
  - 暗号化zipは失敗として扱われる。
  - ログに「暗号化zip非対応」の理由が出力される。

### zip内に有効画像が1枚もない場合は失敗する
- **前提**
  - zip内が非画像ファイルのみ、または空zipである。
- **操作**
  - import を実行する。
- **結果**
  - zipは失敗となる。
  - 理由として画像なしが出力される。

### zip内ディレクトリ配下の画像は対象外とする
- **前提**
  - zip直下に画像はなく、サブディレクトリ内にのみ画像がある。
- **操作**
  - import を実行する。
- **結果**
  - 対象画像0件として失敗になる。
  - サブディレクトリ配下画像は無視対象として扱われる。

### 許可拡張子以外のファイルは画像実体でも無視する
- **前提**
  - zip直下に拡張子なしファイル（実体は画像）がある。
- **操作**
  - import を実行する。
- **結果**
  - 当該ファイルは非対応拡張子として無視される。
  - ファイル単位の理由付きログが出力される。

### 画像が1枚でも破損していればzip全体を失敗する
- **前提**
  - zip内に正常画像と破損画像が混在する。
- **操作**
  - import を実行する。
- **結果**
  - zip全体が失敗として扱われる。
  - メディア登録は行われない。

### 保存失敗時はzip失敗として記録し次zipへ継続する
- **前提**
  - あるzipでcontent保存またはメディア保存が失敗する。
  - 後続に処理可能なzipが存在する。
- **操作**
  - import を実行する。
- **結果**
  - 失敗zipは `error` ログで理由が出力される。
  - 後続zip処理は継続される。

## 正常系

### zip以外の直下エントリはスキップして処理継続する
- **前提**
  - 直下に zip と非zip（ファイル/ディレクトリ）が混在する。
- **操作**
  - import を実行する。
- **結果**
  - 非zipはスキップログが出力される。
  - zipのみ登録対象として処理される。

### zip拡張子は大文字小文字を区別せず対象にする
- **前提**
  - `A.zip`, `B.ZIP`, `C.ZiP` が存在する。
- **操作**
  - import を実行する。
- **結果**
  - すべてzipとして処理対象になる。

### 非画像ファイルは無視しファイルごとに理由付きログを出力する
- **前提**
  - zip内に有効画像と非画像ファイルが混在する。
- **操作**
  - import を実行する。
- **結果**
  - 非画像は無視される。
  - 無視ログはファイルごとに1行で出力される。
  - 画像が1枚以上あれば登録処理は継続される。

### 許可画像拡張子は大文字小文字を区別せず対象にする
- **前提**
  - zip内に `a.JPG`, `b.JPEG`, `c.PnG`, `d.GIF`, `e.WeBp` が存在する。
- **操作**
  - import を実行する。
- **結果**
  - すべて有効画像として扱われる。
  - 画像が1枚以上あれば登録処理は継続される。

### 画像はbasenameの自然順でcontent登録される
- **前提**
  - zip直下に `1.jpeg`, `2.jpeg`, `10.jpeg`, `A.jpeg`, `a.jpeg` が存在する。
- **操作**
  - import を実行する。
- **結果**
  - content登録順が basename の自然順となる。
  - 大文字小文字は区別される。

### タイトルはzip拡張子除去後のファイル名を利用する
- **前提**
  - zipファイル名が `my.book.v1.zip` である。
- **操作**
  - import を実行する。
- **結果**
  - メディアタイトルは `my.book.v1` になる。

### 同名タイトルが既存にあっても登録可能である
- **前提**
  - 同名タイトルのメディアが既に存在する。
  - 新規zipの内容は有効である。
- **操作**
  - import を実行する。
- **結果**
  - 重複チェックで弾かれず登録成功する。

### 同一zipの再importは毎回新規登録される
- **前提**
  - 同一zipを2回連続で実行する。
- **操作**
  - import を2回実行する。
- **結果**
  - 2回とも登録が成功し、それぞれ別メディアとして保存される。

### zipが0件の場合は全件成功として終了コード0になる
- **前提**
  - 対象ディレクトリ直下にzipが1件も存在しない。
- **操作**
  - import を実行する。
- **結果**
  - zip処理対象は0件となる。
  - サマリ（総件数0/成功件数0/失敗件数0）が出力される。
  - 終了コードは0となる。

### 全件成功時は終了コード0でサマリを出力する
- **前提**
  - 対象zipがすべて正常である。
- **操作**
  - import を実行する。
- **結果**
  - すべて success ログとなる。
  - サマリ（総件数/成功件数/失敗件数）が出力される。
  - 終了コードは0となる。

### 一部成功時は終了コード1でサマリを出力する
- **前提**
  - 正常zipと失敗zipが混在する。
- **操作**
  - import を実行する。
- **結果**
  - 成功/失敗が混在した結果ログになる。
  - サマリが出力される。
  - 終了コードは1となる。

### 全件失敗時は終了コード2でサマリを出力する
- **前提**
  - すべてのzipが失敗条件に該当する。
- **操作**
  - import を実行する。
- **結果**
  - すべて failure ログになる。
  - サマリが出力される。
  - 終了コードは2となる。

## medium テスト方針
- small では zip判定・画像拡張子判定・自然順ソート・終了コード決定など副作用の少ないロジックを優先検証する。
- medium では `createDependencies` で組み立てた実依存（DB/保存先/ログ）を使い、CLI 実行から登録結果までを確認する。
- ログ検証は文面完全一致ではなく、重要フィールド（対象zip、結果、理由、件数）を中心に検証する。
- fixture は `__tests__/fixtures/importZips/` を利用する。
