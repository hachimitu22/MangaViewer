# 漫画閲覧

## 概要
利用者が選択した漫画閲覧を開始する。
ページ送り操作により、複数ページを順に表示できる。

## アクター
- 閲覧者
- 管理操作利用者

## 事前条件
- メディア詳細表示したメディア種別が漫画である

## 事後条件
- 利用者が選択したページが表示されている
- 前後のページ遷移操作が可能な状態になっている

## トリガー
- 閲覧者がメディア詳細から任意のページのサムネイルを選択する

## 基本フロー
1. 閲覧者はメディア詳細から任意のページのサムネイルを選択する
2. システムは選択されたページを表示する
3. 閲覧者は前後ページを選択する
4. システムは選択されたページを表示する
5. 3と4を閲覧者が操作を終えるまで繰り返す

## 代替フロー
- 先頭ページで前ページを選択した場合、現在のページを維持する
- 終端ページで次ページを選択した場合、現在のページを維持する

## 関連ユースケース
- メディア詳細表示(事前)
